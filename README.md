# CLF Resources

Source for the public CLF Church resources site at [resources.clf-church.com](https://resources.clf-church.com/).

The site is built with Astro and contains the articles currently published for church members. The original source files and editorial working material are kept separately.

## Local development

```sh
npm ci
npm run dev
```

## Verify and build

```sh
npm run check
npm run build
```

Article text and church media are published for reading on the site. No reuse license is granted for that material.
